CASE 01-B · AI AGENT PORTING & TRADE-OFF OPTIMIZATION

기기의 한계를 극복한 최적화: 프로토타입 안내 로봇 ‘Rumi’ 개조 프로젝트

2026 고려대학교 생물심리 연구실 인턴 · 심리학부 전용 안내 시스템 프로토타입

AI 에이전트 이식 웹 크롤링 · PDF 학습(RAG) 경량화 최적화 Google · Naver 검색 API

2026년 고려대학교 생물심리 연구실 인턴으로 참여해, 향후 관공서 및 타 대학 맞춤형 안내 로봇 개발을 위한 프로토타입으로 상용 로봇 ‘Rumi’를 심리학부 전용 안내 시스템으로 개조했습니다.

선행 사례나 지도 인력이 없는 환경에서도 기술 서적을 탐구해 타 기기에 AI 에이전트를 직접 이식했으며, 하드웨어 스펙 한계에 부딪혔을 때 기술적 이상향보다 ‘현장의 안정적 검증’을 선택해 경량화와 외부 검색 API 연동으로 우회 돌파한 실질적 최적화 경험입니다.

SYSTEM ARCHITECTURE & TRADE-OFF

제한된 하드웨어에서 최선의 안정성을 끌어낸 3단계 설계

01 · PHYSICAL DOMAIN SAFETY

계단·엘리베이터 등 2층 이상 이동 시 파손 위험을 사전 분석해 구동 반경을 1층으로 제한하고, 1층 내부 이동·목적지 안내 행동 가이드를 직접 설계.

02 · DATA PIPELINE (RAG APPLICATION)

학교 홈페이지를 웹 크롤링 → PDF 변환 → 학습(RAG 방식 응용)하여 위치 안내 데이터를 구축하고, 로봇 디스플레이에는 학부 영상을 상시 송출하도록 통합.

03 · HARDWARE SPEC TRADE-OFF

대화형 AI 에이전트 이식 후 기기 사양 한계로 잦은 오류 발생 → 안정적 프로토타입 검증을 우선 선택.

고부하 전체 대화형 AI
(기기 스펙 한계·잦은 오류) → 특정 음성·키워드 경량화
+ Google·Naver 검색 API 연동
기 목표 설정 & 물리적 한계 사전 분석

고려대 생물심리 연구실 인턴으로서 관공서·대학 맞춤형 안내 로봇 프로토타입을 맡아 상용 로봇 ‘Rumi’를 개조했습니다. 먼저 기기의 물리적 한계와 파손 위험을 분석해 2층 이상 이동을 배제하고 활동 반경을 1층으로 제한한 맞춤형 행동 가이드를 새롭게 설계했습니다.

승 크롤링·PDF 학습(RAG) & 미디어 통합

심리학부 전용 안내를 위해 학교 홈페이지를 웹 크롤링한 뒤 PDF로 변환·학습시켜 위치 안내 시스템을 구축하고, 로봇 디스플레이에는 학부 영상을 상시 송출해 기관 특화 프로토타입 구성을 완성했습니다.

전 기기 스펙 한계 돌파 — 경량화 & 검색 API 우회

대화형 AI 에이전트를 이식했으나 하드웨어 사양 한계로 잦은 오류가 발생했습니다. 고도화 기능에 매몰되기보다 현장의 안정적 검증이 우선이라 판단해 특정 음성·키워드 반응으로 경량화하고, 축소된 정보 탐색은 Google·Naver 검색 API 연동으로 실시간 보완했습니다.

결 자기주도 이식 완수 & 현실적 최적화 역량 증명

지도 인력과 선행 사례가 없는 조건에서도 기술 서적을 탐구하며 타 기기에 AI 에이전트를 성공적으로 이식했습니다. 기술적 이상향에 갇히지 않고 제한된 환경 속에서 최선의 타협안(Trade-off)을 도출하는 실질적 AI 엔지니어링·문제 해결 역량을 증명했습니다.

PIPELINE 02-B · BIOSIGNAL CAPTURE TO REPLAY ANALYSIS

Recorder로 아두이노 심박을 재고(.txt / .xlsx), Player로 이미 잰 데이터를 파형 시각화·시점 분석

Arduino · 9600 baud Web Serial API HTML5 Canvas .txt · .xlsx Export

심장박동 데이터를 한 번에 측정·저장·분석하기 위해 역할을 분리한 2-앱 연동 분석 도구입니다. Heart Rate Serial Recorder로 Chrome/Edge에서 아두이노 심박 센서에 직접 연결해 실시간 BPM을 재고 원시 시리얼 로그(.txt)와 엑셀(.xlsx)을 남긴 뒤, Heart Rate Player에서 이미 측정한 데이터를 불러와 타임스탬프 기반으로 정밀 분석합니다.
